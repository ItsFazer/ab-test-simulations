# Критерий Уэлча и мощность A/B-теста

Учебная работа Т-Академии по статистике. Реализую t-статистику и двустороннее p-value, затем проверяю поведение критерия на синтетических данных.

## Что внутри

- Своя реализация статистики и числа степеней свободы.
- Сравнение результата с scipy.stats.ttest_ind при equal_var=False.
- Распределение t-статистики при разных n.
- Серия из 1 000 A/A-тестов и оценка ложных отклонений H₀.
- Кривые мощности для n = 50, 1 000, 10 000 и изменения среднего от 0% до 5%.

Откройте [analysis.ipynb](analysis.ipynb): в нём код, выполненные результаты и графики. Таблица кривых сохранена в [power_curves.csv](power_curves.csv).

## Запуск

`pip install -r requirements.txt`, затем открыть ноутбук и выполнить Restart Kernel → Run All. Данные генерируются внутри; внешних файлов и ключей нет. Полный запуск симуляций может занять несколько десятков секунд.

## Ограничения

Симуляционные частоты имеют погрешность, зависящую от числа повторов. Выводы относятся к выбранным распределениям и независимым наблюдениям. Это учебное моделирование, а не эксперимент компании.
